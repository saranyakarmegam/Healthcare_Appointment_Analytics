# Healthcare Patient & Appointment Analysis

An end-to-end healthcare analytics project using **Python, SQL, and Power BI** to analyze patient appointments, departments, doctors, revenue, waiting times, appointment status, insurance types, and medical conditions.

## Project Overview

This project transforms healthcare appointment data into meaningful analytical insights through:

- Data cleaning and preprocessing using Python
- Relational database design and SQL analysis
- Interactive data visualization using Power BI
- KPI development and business-oriented reporting

The project works with three main datasets: **Patients, Appointments, and Departments**.

## Tools & Technologies

| Technology | Purpose |
|---|---|
| Python | Data cleaning and preprocessing |
| Pandas | Data manipulation and transformation |
| MySQL | Database creation and SQL analysis |
| SQL | Data querying and analytical analysis |
| Power BI | Interactive dashboard and visualization |
| Power Query | Data transformation |
| DAX | KPI and analytical calculations |
